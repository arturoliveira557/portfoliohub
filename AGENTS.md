# Instruções para Agentes de IA

Você está colaborando em um projeto SDD chamado PortfolioHUB.

## Diretrizes

1. Leia `docs/especificacao_sdd.md` antes de sugerir código.
2. Mantenha as funções pequenas e testáveis.
3. Não altere o escopo sem registrar em `docs/feedback_refinamento.md`.
4. Sempre que criar uma função, crie ou atualize testes em `tests/`.
5. Não inclua senhas, tokens, chaves privadas ou dados sensíveis.
6. Preserve a estrutura de branches: `main`, `develop`, `feature/*`.
