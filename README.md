# PortfolioHUB

Este repositório foi criado para a atividade **Criação de Repositório com Versionamento**, com o objetivo de organizar projetos acadêmicos e pessoais utilizando Git, GitHub e GitHub Pages.

## Objetivo

O objetivo deste projeto é criar um portfólio profissional com estrutura organizada, documentação e publicação de uma página web pelo GitHub Pages.

## Estrutura do Repositório

- `index.html`: página principal do projeto.
- `style.css`: arquivo de estilos da página.
- `CHANGELOG.md`: registro das alterações realizadas.
- `diario-versionamento.md`: anotações sobre o processo de versionamento.
- `entrega-final.md`: informações finais da entrega.
- `GUIA_PASSO_A_PASSO.md`: guia explicativo da atividade.

## Tecnologias Utilizadas

- Git
- GitHub
- HTML
- CSS
- GitHub Pages
- LinkedIn

## Versionamento

O projeto foi versionado no GitHub por meio de commits, registrando as alterações feitas durante o desenvolvimento.

## GitHub Pages

A página web do projeto será publicada utilizando o GitHub Pages.
