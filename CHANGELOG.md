# Diário de Versionamento

Este documento registra uma sugestão de histórico de commits para demonstrar o uso do Git.

## Commit 1

**Mensagem:** `versao 1.0: estrutura inicial do PortfolioHUB`

**Descrição:** criação da estrutura de pastas, página inicial, arquivos CSS e JavaScript.

## Commit 2

**Mensagem:** `docs: adiciona planejamento e readmes dos projetos`

**Descrição:** inclusão do README principal, documentação do projeto acadêmico e planejamento do repositório.

## Commit 3

**Mensagem:** `feat: adiciona secao de links para entrega`

**Descrição:** atualização da página inicial com campos para GitHub, GitHub Pages, LinkedIn e YouTube.

## Commit 4

**Mensagem:** `docs: adiciona roteiro da apresentacao final`

**Descrição:** criação do roteiro para vídeo de apresentação de 5 minutos.

## Exemplo de fluxo de trabalho

```bash
git status
git add .
git commit -m "mensagem objetiva da alteracao"
git push
```
