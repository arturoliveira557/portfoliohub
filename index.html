PortfolioHUB

Repositório criado para a atividade de versionamento com Git, GitHub e GitHub Pages

Sobre o Projeto

Este projeto foi desenvolvido como parte da atividade de criação de repositório com versionamento. O objetivo é organizar projetos acadêmicos e pessoais em um repositório público no GitHub, utilizando boas práticas de documentação, versionamento e publicação com GitHub Pages.

Estrutura do Repositório

  • README.md: documentação principal do projeto.
  • index.html: página inicial publicada no GitHub Pages.
  • style.css: arquivo de estilos do projeto.
  • CHANGELOG.md: registro das alterações feitas no repositório.
  • diario-versionamento.md: anotações sobre o processo de versionamento.
  • entrega-final.md: checklist e informações finais da entrega.

Tecnologias Utilizadas

  • Git
  • GitHub
  • GitHub Pages
  • HTML
  • CSS
  • LinkedIn
